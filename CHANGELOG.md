## [0.1.0] — 2024

### Added
- Import builds via Maxroll.gg planner link or ID
- Full item display: implicits, affixes, greater affixes and tempered affixes
- Green/red visual indicators per affix
- Multi-language affix support — 10+ locales (EN, DE, ES, FR, IT, JA, KO, PL, PT, RU, TR, ZH)
- Side-by-side build comparison (Build A vs Build B)
- NestJS REST API with Swagger at `/api/v1/swagger`
- Angular 17 frontend with Tailwind CSS
- Turborepo monorepo with npm workspaces
