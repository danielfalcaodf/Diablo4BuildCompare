# Security Policy

## Supported Versions

As this project is in early development, only the latest version on the `master` branch receives security fixes.

| Version | Supported |
|---------|-----------|
| master (latest) | ✅ |

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue to report security vulnerabilities.**

If you find a vulnerability, report it responsibly:

1. Send an email to **danielfalcao.df@gmail.com** with the subject: `[SECURITY] Diablo4BuildCompare`
2. Include as much detail as possible:
   - Type of vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

You will receive a response within **72 hours** confirming receipt.  
After review, you will be informed of the decision (fix, mitigate, or dismiss) and the estimated timeline.

Thank you for helping keep this project safe! 🔒
